PESAN CARD — WEBSITE PESAN DARI EXCEL

Isi folder:
- index.html   : halaman publik
- admin.html   : import data dari Excel
- admin.js     : parser Excel clipboard + export
- app.js       : card dan halaman penerima
- style.css    : tampilan
- data.js      : 107 data dari file Excel yang kamu kirim

CARA PAKAI:
1. Buka index.html untuk melihat data yang sudah dimasukkan.
2. Buka admin.html untuk memasukkan Excel baru.
3. Di Excel: Ctrl+A -> Ctrl+C.
4. Di admin.html: Ctrl+V -> Import Data.
5. Klik Download data.js.
6. Ganti file data.js lama dengan file hasil download.
7. Upload ulang folder website ke hosting.

LINK PENERIMA:
Website otomatis membuat link seperti:
?to=kak-melky
?to=kak-yoel
?to=kak-nurhalim-kak-nung
?to=kak-erlisa-kak-cutak

CATATAN PRIVASI:
Website ini bersifat statis. Data pesan yang dipublikasikan ke hosting menjadi bagian dari website dan bukan database privat. Jangan memasukkan data pribadi/sensitif yang tidak ingin dapat diakses publik.
